# 黯渊崛起 — 游戏内实时修改器（方案 B）

仿照「觅长生内置修改器」的思路，为《黯渊崛起》做一个**游戏内 GUI 修改器**：
游戏里按 **F10**（或点右上角「修改器」按钮）即可呼出菜单，实时开关作弊功能。

---

## 一、原理

游戏是 RPG Maker MZ（NW.js / JavaScript）。方案 B 通过**注入一个自定义插件**实现：

1. 把 `AnYuan_Trainer.js` 放进 `<游戏>/js/plugins/`
2. 在 `<游戏>/js/plugins.js` 的 `$plugins` 数组末尾追加一条记录

插件在游戏内：
- **Hook 关键方法** 实现实时效果（`Game_Actor.refresh`、`Game_Battler.gainHp`、`Game_Player.updateEncounterCount`、`Game_CharacterBase.distancePerFrame`、`SceneManager.updateMain`）
- **新建一个 RMMZ 场景** `Scene_Cheat`（原生窗口界面，↑↓ 选择 / ←→ 或 Z 执行 / X 或 F10 关闭）
- **注入主菜单入口**：照抄本游戏插件 `BZ_EncyclopediaHub` 的写法，
  用 `Window_MenuCommand.addOriginalCommands` + `Scene_Menu.createCommandWindow` 在主菜单加一项「修改器」
- 通过 **NW.js DOM** 在右上角放一个可点击的「修改器」按钮

> 与方案 A（存档修改器）的区别：方案 B 是**实时**的，进游戏就能用；
> 方案 A 是改存档文件、需要退出游戏。两者可共存。
>
> 统一入口在上一级的 `启动器.bat`（安装 / 卸载 / 状态 / 自检 / 打开存档修改器）。

## 二、安装 / 卸载

### 方式 1：双击（推荐）

- 双击 **`安装修改器.bat`** → 注入插件
- 双击 **`卸载修改器.bat`** → 还原原版

### 方式 2：命令行

```bash
node install.js             # 安装（默认游戏目录）
node install.js status      # 查看状态
node install.js uninstall   # 卸载
node install.js --game "D:\Games\暗渊崛起 Demo" install   # 指定游戏目录
```

安装时会：
1. 把 `js/plugins.js` 备份到本目录 `backups/`
2. 复制插件到 `<游戏>/js/plugins/AnYuan_Trainer.js`
3. 在 `$plugins` 末尾追加记录（174 → 175 个插件）

卸载时会用备份**逐字节还原** `plugins.js`，并删除插件文件。

## 三、界面操作

| 操作 | 按键 |
|---|---|
| 打开 / 关闭 | **F10**，或 **主菜单 → 「修改器」**，或点右上角「修改器」 |
| 选择项目 | ↑ ↓ |
| 执行 / 切换开关 / 倍速循环 | **Z** 或 **回车**，或 ← → |
| 关闭 | **X** 或 **Esc** 或 F10 |

界面顶部显示上次操作结果，底部显示当前选中项说明；
开关项右侧显示 `● 开` / `○ 关`，倍速项右侧显示当前倍率（如 `2x`）。

## 四、功能列表

### 交互式编辑

| 功能 | 说明 |
|---|---|
| **添加物品…** | 按 物品 / 武器 / 防具 分类浏览全部条目（350 / 193 / 267），←→ 或 Q/W 翻页，选中后输入数量添加 |
| **设置金币…** | 输入精确金币数量 |
| **设置角色等级…** | 选择队伍角色 → 输入等级 |
| **修改变量 / 开关…** | 浏览全部变量(99) / 开关(235)，选一项改数值 |
| **存档信息** | 显示金币 / 时长 / 队伍 / 背包 / 宠物 |

数量/数值输入的按键：`←→ ±1`、`↑↓ ±10`、`Q/W ±100`、`Z 确认`、`X 取消`。

> 列表采用**分页**（每页约 7~14 项），避免一次性创建超大位图导致内存占用过高。

### 倍速

| 功能 | 可选值 | 说明 |
|---|---|---|
| **全局倍速** | 1x / 2x / 3x / 4x | 地图、战斗、动画、计时器整体加速 |
| **战斗加速** | 1x / 2x / 3x / 4x | 仅战斗中加速（与全局倍速取较大值） |

> 实现：一帧内多次执行 `SceneManager.updateMain()`，等效于多跑几帧；
> 关键是在额外帧里**冻结输入状态**（`Input.update`）并让 `Input.isTriggered/isRepeated/isPressed` 返回 false，
> 否则会出现「按键触发一次但菜单/游戏响应多次」或「按键完全无响应」。

## 五、注意事项

- **需要 Node.js**（安装器和测试脚本用；玩游戏本身不需要）。
- 安装会**修改游戏文件**（`js/plugins.js` + 新增一个 js 文件）。已自动备份，可一键还原。
- **Steam 更新/校验游戏** 可能覆盖 `plugins.js`，届时重新安装即可。
- 若游戏内打不开：
  1. 确认 `node install.js status` 显示「已安装 ✓」
  2. 把 `js/plugins.js` 里 `AnYuan_Trainer` 的 `"status"` 改成 `true`
  3. 或改插件参数 `openKeyCode`（F8=119 / F9=120 / F10=121 / F11=122 / F12=123）
- 也可以从 **主菜单 → 「修改器」** 打开，不依赖热键。
- 右上角按钮可通过插件参数 `showButton` 关闭。
