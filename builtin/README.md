# 黯渊崛起 — 游戏内实时修改器

仿照「觅长生内置修改器」的思路，为《黯渊崛起》做一个**游戏内 GUI 修改器**：
游戏里按 **F10**（或点右上角「修改器」按钮）即可呼出菜单，实时开关作弊功能。

---

## 一、原理

游戏是 RPG Maker MZ（NW.js / JavaScript）。内置修改器通过**注入一个自定义插件**实现：

1. 把 `AnYuan_Trainer.js` 放进 `<游戏>/js/plugins/`
2. 在 `<游戏>/js/plugins.js` 的 `$plugins` 数组末尾追加一条记录

插件在游戏内：
- **Hook 关键方法** 实现实时效果（`Game_Actor.refresh`、`Game_Battler.gainHp`、`Game_Player.updateEncounterCount`、`Game_CharacterBase.distancePerFrame`、`SceneManager.updateMain`）
- **新建一个 RMMZ 场景** `Scene_Cheat`（原生窗口界面，↑↓ 选择 / ←→ 或 Z 执行 / X 或 F10 关闭）
- 通过 **NW.js DOM** 在右上角放一个可点击的「修改器」按钮

> 打开方式只有两种：**F10** 或 **右上角按钮**（未注入主菜单）。

> 与存档修改器的区别：内置修改器是**实时**的，进游戏就能用；
> 存档修改器改的是存档文件，需要先退出游戏。两者可共存。
>
> 统一入口在上一级的 `启动器.bat`（安装 / 卸载 / 状态 / 自检 / 打开存档修改器）。

## 二、安装 / 卸载

### 方式 1：双击（推荐）

- 双击 **`安装修改器.bat`** → 注入插件
- 双击 **`卸载修改器.bat`** → 还原原版

### 方式 2：命令行

```bash
node install.js             # 安装（默认游戏目录）
node install.js status      # 查看状态
node install.js uninstall   # 卸载
node install.js --game "D:\Games\暗渊崛起 Demo" install   # 指定游戏目录
```

安装时会：
1. 把 `js/plugins.js` 备份到本目录 `backups/`
2. 复制插件到 `<游戏>/js/plugins/AnYuan_Trainer.js`
3. 在 `$plugins` 末尾追加记录（174 → 175 个插件）

卸载时会用备份**逐字节还原** `plugins.js`，并删除插件文件。

## 三、界面操作

| 操作 | 按键 |
|---|---|
| 打开 / 关闭 | **F10**，或点右上角「修改器」按钮 |
| 选择项目 | ↑ ↓ |
| 执行 / 切换开关 / 倍速循环 | **Z** 或 **回车**，或 ← → |
| 关闭 | **X** 或 **Esc** 或 F10 |

界面顶部显示上次操作结果，底部显示当前选中项说明；
开关项右侧显示 `● 开` / `○ 关`，倍速项右侧显示当前倍率（如 `2x`）。

## 四、功能列表

> ⚠ **适度使用提醒**：修改太强会让游戏很快失去乐趣。
> 建议优先用【便利功能】的倍率/加速，少用【一键修改】。
> 修改器的状态栏也会常驻显示这条提醒。

### 便利功能（降肝但不毁游戏）

这些功能只降低肝度，不直接破坏成长与挑战：

| 功能 | 可选值 | 说明 |
|---|---|---|
| **经验倍率** | 1x / 2x / 3x / 5x | 战斗获得经验 ×N |
| **金币倍率** | 1x / 2x / 3x / 5x | 战斗获得金币 ×N |
| **掉宝倍率** | 1x / 2x / 3x / 5x | 战利品掉率 ×N |
| **全局倍速** | 1x / 2x / 3x / 4x | 地图/战斗/动画整体加速 |
| **战斗加速** | 1x / 2x / 3x / 4x | 仅战斗中加速 |
| **移动加速** | 开关 | 地图移动速度 ×2 |
| **不遇敌** | 开关 | 地图上不触发随机战斗 |
| **自动满血** | 开关 | 队伍成员始终保持满血 |
| **无限MP/TP** | 开关 | MP、TP 保持全满 |

> 三个倍率直接挂在游戏自带的 `BZ_ExpAndDropRateBonus` 获取率体系上，
> 只影响**战斗奖励**（`expTotal` / `goldTotal` / `dropItemRate`），
> 不会把数值直接拉满，保留成长与打宝的乐趣。

### 交互式编辑（逐项查看并修改）

| 功能 | 说明 |
|---|---|
| **添加物品…** | 浏览全部 **物品 350 / 武器 193 / 防具 267** 项，输入数量添加 |
| **背包物品数量…** | 只列出**已拥有**的物品，直接把数量设为指定值（设为 0 即移除） |
| **设置角色等级…** | 选择队伍角色 → 输入等级 |
| **设置金币…** | 输入精确金币数量 |
| **修改变量 / 开关…** | 浏览全部变量(99) / 开关(235)，选一项改数值 |
| **存档信息** | 显示金币 / 时长 / 队伍 / 背包 / 宠物 / 当前获取率 |

**列表类界面统一操作**（添加物品 / 背包物品数量 / 设置等级 / 改变量）：

| 按键 | 作用 |
|---|---|
| ↑ ↓ | 上下选择 |
| ← → | **直接切换类别**（物品/武器/防具、变量/开关），**无需按 Esc** |
| Q / W | 翻页 |
| **鼠标滚轮** | **翻页**（已禁用原生滚动，不会再出现选中框错位） |
| Z / 回车 | 选定 → 进入数量输入 |
| X / Esc / F10 | 返回上一层 |

**数量/数值输入**：`←→ ±1`、`↑↓ ±10`、`Q/W ±100`、`滚轮 ±1`、`Z 确认`、`X 取消`。

每页显示 **14 行**，状态栏会显示「共 N 项　第 x/y 页」。

> 列表采用**分页**（而非长列表滚动）：内容高度 == 可视高度，使 `maxScrollY()==0`，
> 从根本上避免 RMMZ 的 `ensureCursorVisible` / 滚轮滚动导致选中框跑到窗口外。

### 战斗辅助

| 功能 | 说明 |
|---|---|
| **无敌模式** | 队伍成员不会掉血、不会死亡 |
| **一击必杀** | 我方造成伤害时敌人立即死亡 |
| **穿墙** | 角色可穿过障碍物 |

> 倍速实现：一帧内多次执行 `SceneManager.updateMain()`，等效于多跑几帧；
> 关键是在额外帧里**冻结输入状态**（`Input.update`）并让
> `Input.isTriggered/isRepeated/isPressed` 返回 false，
> 否则会出现「按键触发一次但游戏响应多次」或「按键完全无响应」。

## 五、注意事项

- **需要 Node.js**（安装器和测试脚本用；玩游戏本身不需要）。
- 安装会**修改游戏文件**（`js/plugins.js` + 新增一个 js 文件）。已自动备份，可一键还原。
- **Steam 更新/校验游戏** 可能覆盖 `plugins.js`，届时重新安装即可。
- 若游戏内打不开：
  1. 确认 `node install.js status` 显示「已安装 ✓」
  2. 把 `js/plugins.js` 里 `AnYuan_Trainer` 的 `"status"` 改成 `true`
  3. 或改插件参数 `openKeyCode`（F8=119 / F9=120 / F10=121 / F11=122 / F12=123）
  4. 也可以直接点屏幕右上角的「修改器」按钮，不依赖热键。
- 右上角按钮可通过插件参数 `showButton` 关闭。
