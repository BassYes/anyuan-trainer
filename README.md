# 黯渊崛起 修改器

针对 RPG Maker MZ 游戏《黯渊崛起》（`暗渊崛起 Demo`）的修改器套件。

**以「内置修改器」为主**：注入一个游戏内插件，游戏里按 **F10** 或点右上角
「修改器」按钮即可呼出图形界面，实时作弊、加物品、改数值，**不用退出游戏**。
**「存档修改器」作为辅助**：直接读写 `save/*.rmmzsave`，适合游戏打不开时改存档。

## 一、快速开始

双击 **`启动器.bat`**，出现菜单：

```
========== 黯渊崛起 修改器 ==========
游戏目录: E:\SteamLibrary\steamapps\common\暗渊崛起 Demo
内置修改器: 未安装
-------------------------------------
 ── 内置修改器（推荐，游戏内实时）──
   [1] 安装 / 更新
   [2] 卸载（还原原版）
   [3] 查看安装状态
   [4] 运行自检
 ── 存档修改器（改存档文件）──
   [5] 打开存档修改器
 ── 其他 ──
   [g] 设置游戏目录
   [0] 退出
```

1. 选 `[1]` 安装内置修改器
2. 启动游戏
3. 按 **F10**，或点**右上角「修改器」**按钮
4. 用完想还原原版：选 `[2]` 卸载

## 二、内置修改器（主）

### 打开方式（两种）

| 方式 | 说明 |
|---|---|
| **F10** | 地图、菜单里都能按 |
| **右上角「修改器」按钮** | 鼠标点击，NW.js 悬浮按钮 |

界面操作：`↑↓` 选择，`Z`/回车 执行，`X`/`Esc` 关闭。

### 功能

> ⚠ **适度使用提醒**：修改太强会让游戏很快失去乐趣。
> 建议优先用【便利功能】的倍率/加速，少用【一键修改】；
> 修改器状态栏也会常驻显示这条提醒。

**便利功能（降肝但不毁游戏）**

| 功能 | 可选 |
|---|---|
| 经验倍率 / 金币倍率 / 掉宝倍率 | 1x / 2x / 3x / 5x（只影响战斗奖励） |
| 全局倍速（地图/战斗/动画） | 1x / 2x / 3x / 4x |
| 战斗加速 | 1x / 2x / 3x / 4x |
| 移动加速 / 不遇敌 / 自动满血 / 无限MP·TP | 开关 |

> 三个倍率挂在游戏自带的获取率体系上，不会把数值直接拉满，保留成长与打宝的乐趣。

**战斗辅助**：无敌模式、一击必杀、穿墙

**交互式编辑**

| 功能 | 说明 |
|---|---|
| **添加物品…** | 浏览全部 **物品 350 / 武器 193 / 防具 267** 项，输入数量添加 |
| **背包物品数量…** | 只列出**已拥有**的物品，直接把数量设为指定值（设为 0 即移除） |
| **设置角色等级…** | 选择队伍角色 → 输入等级 |
| **设置金币…** | 输入精确金币数量 |
| **修改变量/开关…** | 浏览全部变量(99)/开关(235)，选一项改数值 |
| **存档信息** | 显示金币/时长/队伍/背包/宠物/当前获取率 |

列表类界面统一操作：`↑↓` 选择、**`←→` 直接切类别**、`Q/W` 或**鼠标滚轮**翻页、
`Z` 选定、`X` 返回；每页 14 行，状态栏显示「共 N 项　第 x/y 页」。

**一键修改（⚠ 影响游戏寿命）**：金币+100万、队伍满级、属性+9999、满血蓝、
全物品×99、全技能、图鉴全解锁、全宠物、精通拉满、觉醒拉满、冒险者任务、门派日常、
清商店限购/装备锁/红点、重置礼包码、**★ 一键全解锁**

> 一键功能改的是**运行中的游戏内存**，想要保留请在游戏内**正常存档**。
> 命令菜单按【便利功能】【战斗辅助】【交互式编辑】【一键修改】分组显示，
> 破坏性命令名后带 `⚠` 标记。

## 三、存档修改器（辅）

双击 `save-editor/启动存档修改器.bat`，或在启动器里选 `[5]`。

直接读写存档文件（RPG Maker MZ 存档 = `JSON → zlib deflate → UTF-8`），
**必须先完全退出游戏**再改。功能包括金币、等级、物品、变量/开关、图鉴、宠物、
精通、任务、礼包码等（与内置修改器 大体重合，但不需要注入游戏文件）。

详细说明见 `save-editor/README.md`。

## 五、安全与还原

- 安装会**修改游戏文件**：在 `<游戏>/js/plugins.js` 的 `$plugins` 末尾追加一条记录，
  并新增 `<游戏>/js/plugins/AnYuan_Trainer.js`。
- 安装前会自动把 `plugins.js` 备份到 `builtin/backups/`。
- **卸载会逐字节还原** `plugins.js`（已验证与原版完全一致），并删除插件文件。
- 即使备份丢失，卸载也能从 `$plugins` 中精确移除记录并还原（已修复并验证）。
- **Steam 更新/校验游戏**可能覆盖 `plugins.js`，届时重新安装即可。

## 六、常见问题

**Q: 游戏里按 F10 没反应？**
A: 先确认「查看安装状态」显示已安装 ✓；或者直接用屏幕右上角的「修改器」按钮。
   热键冲突的话可改插件参数 `openKeyCode`（F8=119 / F9=120 / F10=121 / F11=122 / F12=123）。

**Q: 需要装 Node.js 吗？**
A: 安装器/启动器需要（https://nodejs.org/）。**玩游戏本身不需要**。

**Q: 两个修改器能同时用吗？**
A: 可以。内置修改器 是实时内存修改；存档修改器 改存档文件。注意存档修改器 改完要先退出游戏。

**Q: 会不会弄坏游戏？**
A: 不会。安装有备份、卸载逐字节还原；存档修改也有自动备份（`trainer_backups/`）。

**Q: 改太狠会不会不好玩？**
A: 会。建议优先用【便利功能】里的**经验/金币/掉宝倍率**和**加速**，
   它们只降低肝度、不破坏成长与挑战；【一键修改】里的满级/属性拉满等请克制使用。
