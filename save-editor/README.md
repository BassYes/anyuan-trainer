# 黯渊崛起 Demo — 存档修改器（方案 A）

针对 RPG Maker MZ 游戏《黯渊崛起》（`暗渊崛起 Demo`）的存档修改工具。
直接读写游戏存档，**不修改任何游戏文件**，安全、可逆。

---

## 一、原理

RPG Maker MZ 的存档格式（已逆向并逐字节验证）：

```
JSON  →  zlib deflate(level 1)  →  二进制串  →  UTF-8 写盘
```

本工具完整复刻了游戏 `js/rmmz_managers.js` 里 `StorageManager` 的读写逻辑：

- **读**：`fs.readFileSync(path, 'utf8')` → `Buffer.from(text, 'latin1')` → `zlib.inflateSync` → `JSON.parse`
- **写**：`JSON.stringify` → `zlib.deflateSync(..., {level:1})` → `buf.toString('latin1')` → `fs.writeFileSync(path, str)`

已用**游戏自带的 `js/libs/pako.min.js`** 做过双向兼容性验证：游戏能 100% 正确读取本工具写出的存档。

角色属性（最大 HP/MP、攻防敏运）的计算也完全复刻了游戏公式：

```
param = round((职业基础值 + _paramPlus + Σ装备 params) × 特性paramRate × 增益paramBuffRate)
```

经与存档实测值比对，**三个角色全部精确吻合**。

## 二、使用方法

### 方式 1：双击启动（推荐）

双击 `启动修改器.bat`，进入交互菜单，按数字选择即可。

### 方式 2：命令行

```bash
node trainer.js                     # 交互菜单
node trainer.js info                # 查看信息
node trainer.js gold 9999999        # 设置金币
node trainer.js maxlevel            # 队伍全员满级
node trainer.js allitems 99         # 全物品/武器/防具 x99
node trainer.js boost 9999          # 全员 +9999 全属性
```

> 默认游戏目录已设为 `E:\SteamLibrary\steamapps\common\暗渊崛起 Demo`。
> 如果游戏换位置，加 `--game "新路径"`，例如：
> `node trainer.js --game "D:\Games\暗渊崛起 Demo" info`
> 指定别的存档：加 `--save file2`（对应 `save/file2.rmmzsave`）。

## 三·补、扩展功能说明

这些功能是从游戏插件（`js/plugins.js` 参数）与存档结构中逆向出来的，**均为存档标记，安全可逆**：

- **图鉴全解锁** `unlockall`
  读取各图鉴插件的配置列表，把怪物/技能/状态/武器/防具/宠物图鉴一次性点亮。
  实测一次可解锁：怪物 +233、技能 +625、状态 +298、武器 +164、防具 +201、宠物 +37。

- **精通拉满** `mastery`
  - 武器精通：对每个武器类型写入满级经验（`floor(baseExp × maxLevel^expCurve)`，即 Lv10）。
  - 技能精通：对角色已学技能写入 `{level: 10, exp: 0}`。
  > 建议先用 `learnall` 再 `mastery`，这样全部技能都有精通。

- **学会全部技能** `learnall`
  取全职业 `learnings` 的并集（123 个技能），加入每个队伍成员的 `_skills`。
  刻意**不使用**“全部 699 个技能”，以免把大量敌人/测试被动技能塞进去导致异常。

- **加入全部宠物** `pets`
  把 37 种宠物的 `actorId` 以**数字格式**写入 `_mkPetRoster`——游戏读档时
  `_mkInitPets()` 会自动把它们构建成 `Game_PetActor` 实例，等同正常获得。
  上限 40，自动去重，并把出战宠物设为第 1 只。

- **任务标记完成** `quests`
  把当前存档中「已接（known）」的任务移入「完成」，并补齐目标完成状态。
  ⚠️ 仅修改任务日志状态，**不会发放任务奖励**（奖励由事件脚本发放）。

- **一键全解锁** `cheatall`
  依次执行：金币 → 满级 → 属性拉满 → 全物品 → 全技能 → 精通拉满 → 图鉴全解锁
  → 全宠物 → 觉醒拉满 → 冒险者任务 → 门派日常 → 清限购 → 清装备锁 → 清红点 → 重置礼包码 → 满血满蓝。
  例：`node trainer.js cheatall 99999999`

- **礼包码** `giftcode`
  - `giftcode list`：列出全部 8 个礼包码及其奖励（在游戏菜单「礼包码」处输入即得**真奖励**）。
  - `giftcode reset`：重置领取记录，可把已领过的再领一遍。
  实测礼包码：`anyuanjueqi2026`(饮血剑)、`chuansongluopan001`(传送罗盘)、`guaji9999`(30分钟挂机卡)、
  `menpai0001`(门派等级重置)、`chongzhushi002`(重铸石)、`qiuyijuexing03`(秋怡觉醒修正)、`molun002`(魔轮)、`modun003`(魔盾)。

- **觉醒值** `awaken`：队伍全员 `_awakenGauge = 100`（游戏内上限即 100）。

- **冒险者任务** `tasklist`：完成全部 11 个冒险者任务，并把
  变量 68「冒险者协会任务积分」= 999999、变量 67「冒险者协会等级」= 99。

- **门派日常任务** `secttask`：四个门派各 3 个日常任务标记完成（含五毒教/忍宗/魔法研究院/圣母神教会）。

- **宝石** `gems`：列出 24 种可镶嵌宝石及其效果（红宝石=ATK、蓝宝石=MAT、黑宝石=DEF 等），
  并补给背包每种 99。> 宝石必须在**带孔装备**（备注含 `<孔数:N>`）上才能镶嵌，基数据装备无孔。

## 四、备份机制

- **首次写盘前会自动备份**到 `<游戏目录>/trainer_backups/`，文件名带时间戳。
- 每次 `node trainer.js backup` 也会生成一个备份。
- `restore` 会恢复**最新**的一个备份。
- 另外游戏自身在保存时也会留一个 `file1.rmmzsave_`。

修改前建议：**先退出游戏**（游戏在退出/保存时会写盘，会覆盖你的修改），
若开启了 Steam 云存档，注意云同步可能覆盖本地存档。

## 六、常见问题

**Q：改完进游戏没生效？**
A：确认改的是当前在读的存档；确认游戏已完全退出后再改；若开了 Steam 云，注意同步方向。

**Q：`fullhp` 为什么要算那么复杂？**
A：因为游戏的「最大 HP」= 职业基础 + 属性加成 + **装备加成** × 特性倍率，不算装备会算少。
本工具精确复刻了公式，不会把血改少。

**Q：会破坏存档吗？**
A：不会。写盘前自动备份；且已用游戏自带 pako 验证读回无误。真出问题用 `restore` 还原。

**Q：能实时开无敌/秒杀吗？**
A：这是方案 A（存档级）。实时功能属于方案 B（游戏内插件）/方案 C（远程注入），后续可再加。
